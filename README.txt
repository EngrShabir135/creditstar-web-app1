CREDITSTAR HTML/CSS/JS REPLICA
===============================

Files:
- index.html
- style.css
- app.js
- assets/  (visual assets extracted from the supplied APK)

For AppsGeyser:
1. Upload/publish these web files using an AppsGeyser HTML5/Website app.
2. The project is front-end only.
3. Login, search, tabs and order cards are demo interactions.
4. The original APK contains backend/API behavior that cannot be reproduced from
   the APK's compiled UI alone. Replace the demo login/API calls with your
   actual server endpoints if you need real data.

The layout uses several visual assets from the supplied APK so the replica
keeps the original visual language and icons.
